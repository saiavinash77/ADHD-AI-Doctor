## 🆘 Troubleshooting

### Issue: Build Fails
**Check:**
- All environment variables added
- No typos in variable names
- Check build logs in Vercel dashboard

**Fix:**
- Redeploy from Vercel dashboard
- Check GitHub Actions tab for errors

### Issue: "Page Not Found"
**Fix:**
- Wait 2-3 minutes for deployment to complete
- Clear browser cache (Ctrl+Shift+R)
- Check Vercel deployment status

### Issue: Clerk Auth Not Working
**Fix:**
- Add Vercel URL to Clerk allowed origins
- Go to Clerk Dashboard → Settings → Domains
- Add: `https://your-app.vercel.app`

### Issue: Payment Button Does Nothing
**Fix:**
- Check browser console (F12) for errors
- Verify Dodo API token in environment variables
- Check serverless function logs in Vercel
